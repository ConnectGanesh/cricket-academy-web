⚙️ Setup & Running

⚠️ npm Issue? Follow the alternative method below if npm is not recognized!

Method 1: Fix npm PATH (If npm is installed)

1

Add Node.js to PATH

Run this in PowerShell:

$env:PATH = "C:\Program Files\nodejs;$env:PATH"
2

Verify npm works

Check if npm is now recognized:

npm --version
3

Navigate to project

Go to the project directory:

cd "C:\Users\PYV1QSS\source\repos\New folder\cricket-academy-web"
4

Install dependencies

Install required packages:

npm install
5

Run development server

Start the development server:

npm run dev
6

View in browser

Open your browser and visit:

http://localhost:3000

Method 2: Use Vercel (No Local Setup Needed!)

✨ Recommended! Skip npm issues entirely by deploying directly to Vercel!
1

Push to GitHub

Commit and push your code:

cd cricket-academy-web git init git add . git commit -m "Cricket Academy Website" git push origin main
2

Go to Vercel

Visit: https://vercel.com/new

3

Import Repository

Click "Import Git Repository" and select your cricket-academy-web repo

4

Deploy

Click "Deploy" - Vercel handles everything!

5

Your site is live!

Get your URL and share it!

🚀 Deployment Guide

Quick Deployment to Vercel (Easiest)

This takes 5 minutes! Vercel handles npm installation automatically.
  1. Create Vercel account: https://vercel.com
  2. Push code to GitHub
  3. Visit https://vercel.com/new
  4. Import your GitHub repository
  5. Click "Deploy"
  6. Wait for deployment (2-3 minutes)
  7. Share your live URL!

Deploy to Railway (Alternative)

  1. Create Railway account: https://railway.app
  2. Connect GitHub account
  3. Select your repository
  4. Railway auto-detects Next.js
  5. Configure environment variables
  6. Deploy automatically

Key Files for Deployment

  • package.json - Dependencies
  • next.config.js - Next.js configuration
  • .env.example - Environment template
  • DEPLOYMENT.md - Detailed guide

🎨 Customization Guide

1. Change Academy Name

File: app/layout.tsx

// Change this line: <h1 className="text-2xl font-bold">Elite Cricket Academy</h1> // To your academy name: <h1 className="text-2xl font-bold">Your Academy Name</h1>

2. Change Colors

File: tailwind.config.js

colors: { primary: '#1e40af', // Change this (primary blue) secondary: '#ea580c', // Change this (secondary orange) }

3. Update Team Data

File: app/teams/page.tsx

const teams = [ { id: 1, name: 'Your Team Name', coach: 'Coach Name', players: 18, wins: 22 }, // Add more teams... ];

4. Update Player Data

File: app/players/page.tsx

const players = [ { id: 1, name: 'Player Name', team: 'Team Name', position: 'Batsman', runs: 1250, wickets: 0 }, // Add more players... ];

5. Add Your Images

Location: public/images/

Place your images in this folder and reference them:

<img src="/images/your-image.jpg" alt="Description" />

6. Update Contact Information

File: app/contact/page.tsx

  • Update academy address
  • Update phone number
  • Update email address
  • Update contact hours

7. Update Other Pages

Edit each page file to customize content:

  • app/about/page.tsx - Academy story
  • app/coaches/page.tsx - Coach profiles
  • app/achievements/page.tsx - Achievements
  • app/tournaments/page.tsx - Tournaments
  • app/gallery/page.tsx - Gallery
